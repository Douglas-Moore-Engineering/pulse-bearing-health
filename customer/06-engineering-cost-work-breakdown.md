# Engineering Cost Work Breakdown

PULSE pre-Azure review v0.1 · 2026-10-10 · Owner: Dr. Douglas Moore · Prepared for review

Fictional customer scenario; proposed design, not implementation or customer approval. Stop boundary: no Azure connection, provisioning, paid resources, site access or production release.

This supplements PULSE-LCC-001 v0.1 with quantities to estimate; it does not replace the cost model or establish a quote. Hours, rates, supplier quotes and actual effort are TBD. Define a low/base/high range from explicit complexity assumptions before pricing, not by back-solving to the $60,000 ceiling.

| Work package | Deliverable / sizing driver | Evidence needed |
|---|---|---|
| WP-01 Discovery/requirements/assurance | Reviews, atomic requirements and concern coverage | Scope, review rounds and actual logged effort |
| WP-02 Data qualification | Rights, inventory, adapters and labels | Dataset files/format/unit counts and supplier permissions |
| WP-03 Baselines and experiments | RMS/kurtosis then eligible learned methods | Experiment count, measured duration/hardware and feature complexity |
| WP-04 Workflow/evidence | Mock CMMS, advisory/review ledger | Interface contracts, UX/review rounds and test scope |
| WP-05 Platform/security | Later identity, private network, storage and workspace | Approved design, services, dated rates and integration effort |
| WP-06 Verification/release | Negative/leakage/security/recovery/performance evidence | Test matrix, defect/rework allowance and independent review costs |
| WP-07 Site adaptation | Sensors, installation, real interfaces and shadow evidence | Vendor quotes, actual regime/asset coverage and IT/OT effort |
| WP-08 Operations/exit | Support, retraining, upgrades and transfer | Agreed staffing term, workload, retention and supplier exit charges |

Reference and site increments must be quoted separately, then reconciled to the total lifecycle model. Cost per work package = approved rate × estimated hours plus nonoverlapping third-party charges. Customer internal effort is a separate line. Do not add internal DME labor to an invoice already priced for that labor. Actuals require logged evidence; AI-generated planning effort is not a customer's billable time record.

Next: inspect actual dataset inventory, estimate task effort, research/quote equipment and services after quantities established, and review uncertainty/contingency with the cost owner. No ROI or payback estimate is produced from this WBS alone.
